# AvianVisitors – Central North America Artwork Pack

This repository contains a pre-generated artwork pack for the AvianVisitors project.

## Included

- 511 bird species
- 1,022 transparent illustrations (perched + flight)
- Pre-generated cutouts
- Sketch assets
- Ready for use with AvianVisitors

## Not Included

The original Gemini reference images are intentionally omitted to reduce repository size by more than 1 GB.
